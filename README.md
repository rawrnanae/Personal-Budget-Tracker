# 💰 Personal Finance Management Tracker | Microsoft Excel

**An Excel-based personal finance tracker designed for Malaysians 🇲🇾**

## 📌 1. Project Overview

Managing personal finances can be challenging without a structured system to monitor daily expenses, monthly budgets, and savings goals.

This project introduces a **Personal Finance Management Tracker**, developed using Microsoft Excel to help users organise their finances, monitor spending habits, and make informed financial decisions.

Designed specifically for Malaysian users, the tracker supports **Malaysian Ringgit (RM)** and integrates financial tracking, automated calculations, and visual dashboards into one workbook.

The tracker is **free to download and customise for personal use**.

## 🎯 2. Project Objectives

- Simplify daily income and expense tracking.
- Reduce manual calculations through Excel automation.
- Compare monthly budgets against actual spending.
- Visualise financial performance using an interactive dashboard.
- Monitor savings progress towards financial goals.
- Encourage better financial awareness and budgeting habits.

## 📊 4. Key Features

### 4.1 Daily Transaction Tracker

Record daily financial transactions in one structured table.

- Track income and expenses.
- Categorise transactions using dropdown menus.
- Record transaction dates, descriptions, and amounts.
- Maintain organised financial records for monthly analysis.

### 4.2 Interactive Financial Dashboard

Get an overview of your monthly financial position.

- Total monthly income
- Total monthly expenses
- Savings overview
- Income versus expenditure comparison
- Spending distribution by category

The dashboard helps users understand their financial position without manually reviewing individual transactions.

### 4.3 Monthly Budget Planner

Manage spending limits across different expense categories.

- Set monthly budgets by category.
- Compare planned and actual spending.
- Monitor remaining budget balances.
- Identify categories approaching or exceeding their budget limits.

Conditional formatting provides visual warnings to help users manage overspending.

### 4.4 Savings Goal Tracker

Monitor progress towards personal financial goals.

- Set a target savings amount.
- Track savings contributions.
- Monitor progress towards the goal.
- Calculate monthly savings targets.

This feature helps users plan for goals such as emergency funds, travelling, or major purchases.

## 🚀 6. How to Use

**Step 1: Download the Workbook**

Download the Excel workbook from this repository and open it using Microsoft Excel.

**Step 2: Set Up Your Budget**

Enter your monthly budget for each spending category.

**Step 3: Record Transactions**

Log your daily income and expenses using the transaction tracker. Select the appropriate categories from the dropdown menus.

**Step 4: Monitor Your Dashboard**

Review your monthly financial summary to understand your income, expenditure, and spending patterns.

**Step 5: Track Savings Goals**

Set your savings targets and monitor your progress over time.

## 💡 7. Financial Insights & Practical Applications

The tracker supports everyday financial decision-making by helping users:

- **Understand spending behaviour:** Identify which categories account for the largest share of expenses.
- **Improve budget control:** Detect overspending through budget variance monitoring.
- **Evaluate financial performance:** Compare income, expenses, and savings.
- **Plan future savings:** Establish realistic monthly contributions towards financial goals.

These features demonstrate how spreadsheet automation and data visualisation can transform financial records into useful information.

## ⚠️ 9. Limitations

- Transactions require manual entry.
- The workbook does not automatically connect to banking systems.
- Financial insights depend on the accuracy and completeness of user-entered data.
- The tracker is intended for personal financial management and educational purposes, not professional financial advice.
